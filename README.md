# Demonstração do Nexus RPG

Mesa virtual de RPG em português. **Abra:** https://cauacaetano.github.io/nexus-rpg-demo/

- Tudo roda no navegador: não há servidor nem conta, e o que você faz fica só no seu navegador.
- A campanha "A Cripta de Vento Baixo", os personagens, o mapa e os retratos são fictícios e desenhados por código.
- Entre como Mestre ou como Jogador. Abra em duas abas (uma de cada) para ver a mesa sincronizar.
- O botão "Reiniciar demonstração" volta tudo ao início.

Este repositório contém só o resultado do build da demonstração. O código-fonte do Nexus RPG é privado.
